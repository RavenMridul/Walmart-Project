
# Walmart-Project
This project explores Walmart sales data to uncover trends, customer behavior, and business performance insights. Using Python for data preparation and PostgreSQL for analysis, it demonstrates practical techniques for transforming raw data into actionable information.

# 🛍️ Walmart Sales Analytics | End-to-End Python & SQL Project

## 📌 Project Overview

This project showcases a complete data analytics workflow using Walmart sales data, simulating the responsibilities of a Data Analyst in a real-world business environment. Starting with raw transactional data, the project covers data cleaning, transformation, feature engineering, database integration, and advanced SQL analysis to uncover meaningful business insights.

By combining Python for data preparation and PostgreSQL/MySQL for analytical querying, the project explores customer behavior, product performance, revenue trends, and branch efficiency. The goal is to transform raw data into actionable intelligence that supports data-driven decision-making and business growth.

* Database Management with PostgreSQL/MySQL

## 📂 Dataset Information

The dataset contains 1,000 transaction records from Walmart branches located in Mandalay, Yangon, and Naypyitaw. Each record captures detailed information about sales transactions, customers, products, payments, and profitability metrics.

### Key Features

* Invoice ID
* Branch
* City
* Customer Type
* Gender
* Product Line
* Unit Price
* Quantity
* VAT
* Total Sales
* Date & Time
* Payment Method
* Cost of Goods Sold (COGS)
* Gross Income
* Gross Margin Percentage
* Customer Rating

---

## 🔄 Data Processing Workflow

### 1. Data Cleaning

* Validated dataset quality
* Checked for missing values and inconsistencies
* Standardized formats and data types
* Prepared data for database loading

### 2. Feature Engineering

Created additional columns to improve analytical capabilities:

* **Time of Day** → Morning, Afternoon, Evening
* **Day Name** → Monday to Sunday
* **Month Name** → January to December

### 3. Database Integration

* Loaded cleaned data into PostgreSQL/MySQL
* Structured tables for efficient querying
* Optimized data for analytical reporting
